Solmar Bay — an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty ($1,666 in USDC). Explore a sun-soaked coastal city on foot and by car, steal cars, dodge the SBPD as your wanted level climbs, and run five story missions for Dario's crew — with traffic, pedestrians, combat, a HUD with a live minimap, synthesised sound, and a save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed.
